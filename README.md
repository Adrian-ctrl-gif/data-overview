# ДатаОбзор

Учебный проект: перенос класса анализа данных в IDE и работа с Git.
Класс `DataFrameReporter` помогает быстро оценить таблицу pandas: выводит
количество строк и столбцов, количество и долю дубликатов, сводную статистику
`describe()`, количество и долю пропусков во всём датафрейме.

## Установка

Понадобится Python 3.12 или новее. Откройте папку проекта в VS Code, затем:

```bash
python3 -m venv venv
source venv/bin/activate
python -m pip install -r requirements.txt
```

В Windows PowerShell окружение активируется командой `venv\Scripts\Activate.ps1`.

Создайте папку `data/` и положите в неё исходный `payments.csv` из задания.
Данные и виртуальное окружение исключены из Git через `.gitignore`.

## Запуск

```bash
python main.py
```

Скрипт выводит два отчёта с параметрами из первой части задания.
Путь к данным определяется относительно `main.py`, поэтому запуск не зависит
от текущей папки терминала.

## Настройки класса

- `float_format='0.05f'` — формат доли пропусков.
- `percent_format='0.02%'` — формат доли дубликатов.
- `include_all=False` — при `True` в `describe()` передаётся `include='all'`.
- `show_report(df, title=None)` — выводит отчёт и необязательный заголовок.

Логика исходного класса сохранена. Класс рассчитан на непустые таблицы;
обработка пустого датафрейма в исходном решении не предусмотрена.

Разработка класса выполнена в ветке `build-reporter` отдельными коммитами.
Структура создана по тексту задания: ссылка на исходный шаблон не была предоставлена.
